Frequently Asked Question

The difference between var, let, and const?
  • var:
    • Function-scoped → Can't access outside of the function.
    • Hoisted → Can access before declaration (value will be undefined).
    • Can declare multiple times in the same scope.
  • let:
    • Block-scoped → Can't access outside of the block.
    • Not hoisted → Can't access before declaration.
    • Cannot declare multiple times in the same scope.
  • const:
    • Same as let, but the value cannot be changed after declaration.
The difference between map(), forEach(), and filter()
  • map: Iterates over an array and returns a new array without changing the original array.
  • forEach: Iterates over an array but does not return anything. The original array remains unchanged.
  • filter: Creates and returns a new array based on a specific filtering condition.
Explain arrow functions and how they are different from regular functions

Arrow Functions: Arrow function is a shortest way to define functions using the => syntax.

How JavaScript Promises work?

Promise: A JavaScript object representing an asynchronous operation with three states:

  • Pending: The operation is in progress.
  • Fulfilled: The operation completed successfully.
  • Rejected: The operation failed.
How closures work in JavaScript

Closure: A function that can access variables from its parent scope even after the parent function has finished executing.
